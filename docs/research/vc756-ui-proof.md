## Browser-only UI proof

Port 5376 was checked free with `lsof -nP -iTCP:5376 -sTCP:LISTEN`. The only server launched was:

```sh
cd apps/desktop
pnpm exec vp dev --mode lab --port 5376 --strictPort
```

The lab served `http://localhost:5376/lab/#tool-refresh-notice`. A headless Chromium with an isolated temporary browser context drove the actual production component and the lab's real generated theme tokens. HTTP requests were restricted to loopback; no provider sign-in or real app data was involved.

Probe command:

```sh
cd apps/desktop
node --input-type=module < ../../.scratch/vc756-gates/ui-proof.mjs
```

The first attempt failed the no-console-errors assertion on five Vite `504 Outdated Optimize Dep` responses during initial dependency optimization. A fresh rerun passed all four combinations, without suppressing console errors:

- Dark, 1280px viewport / 640px row width.
- Dark, 640px viewport / 336px row width.
- Light, 1280px viewport / 640px row width.
- Light, 640px viewport / 336px row width.

For each combination the probe verified:

1. Three rows begin collapsed; no alert role appears.
2. The cold row reads `Tools updated: 3 added`; names are hidden until expansion.
3. Focusing its native summary and pressing Enter expands it, revealing all three added names, `codemode (updated)`, and the trigger.
4. Mouse clicks expand the compatible-update-only and Code Mode rows, revealing their correct names.
5. A mouse click collapses the cold row again.
6. No page exceptions, console errors, document overflow, or row overflow occur.
7. The document's resolved appearance is genuinely light/dark, with different generated foreground colors.

Screenshots: `.scratch/vc756-gates/ui-{dark,light}-{1280,640}-{collapsed,expanded}.png`. The dark 1280px and light 640px expanded captures were also visually inspected: rows remain quiet, legible, and unobstructed. Logs: `ui-proof.log`, `ui-proof-first.log`, `lab.log`.

The gate task terminated its own lab processes (listener PID 51083; pnpm launcher PID 51035). A final `lsof` check found no remaining listener on 5376.

## Limits and decision to confirm

- This proves the component's browser interaction and visual states, not a full ChatPlane/SQLite/engine flow or N−1 compatibility. Those remain the parent task's integration and CI gates.
- The initial proof exposed update-only copy as `0 added` and raw trigger identifiers. Parent integration corrected this to `Tools updated: 1 updated` and sentence-case trigger labels (unknown future triggers still retain their name).
- The final component was rechecked in Volli's Browser tools on the same isolated lab port: native keyboard expansion of all three rows, visible added/updated names and labeled triggers, keyboard collapse, a screenshot of the expanded rows, and no console errors. The lab was stopped afterwards. The earlier four viewport/theme screenshots prove layout; the final screenshot proves the revised copy.
- No other blockers were found in these bounded checks. Results describe the shared working tree at execution time, not a committed head or a green CI gate.
