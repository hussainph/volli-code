Volli × Pi 0.85.0 · implementation map

Inside a Volli context.

The model does not receive “the repository.” It receives a frozen tool manifest, a deterministic system prompt, an append-only message history, and live tool results. Volli decides the product context. Pi owns the loop that turns it into work.

Cache invariant

Within a Session, the tool definitions and system prompt remain byte-stable. The Runtime Brief and live facts sit message-side so they cannot invalidate the prefix ahead of them. Compaction changes message history, not the shared prefix.

The index is hard-bounded

Skills-index resource text is capped at 2,048 characters, about 512 estimated tokens before its RESOURCE delimiter. This checkout's current index is 501 of 1,449 baseline tokens (35%); overflow shortens descriptions, then omits the alphabetic tail with a visible notice. The historical 94% case can no longer recur.

Cache classes are claims

Role-static, project-static, and session-static describe expected reuse. Only provider-reported cacheReadTokens and cacheWriteTokens prove what was actually reused.

The meter of record

Provider usage wins. The local ~4 characters/token rule is for stable comparisons, not billing or context-limit enforcement.

05 · Runtime growth

            
Context arrives by doing.

          

          

            The prompt does not preload file contents, full CLI docs, skill bodies, browser pages,
            or shell output. Calls make those bytes visible, and Pi appends their results to history.
          

        


        

          

            01 / read
            
Files become tool results

            
Pi opens the path through the bound ExecutionEnv. Text is capped at 2,000 lines or 50 KB; images become image content after Volli's processor.

            
  • Not startup context
  • Visible in transcript
  • Re-sent on later model calls until compacted

          

          

            02 / execute → bash
            
Commands append output

            
Volli calls the product capability execute; Pi exposes it on the wire as bash. Combined output is tail-capped; overflow spills to a temp file.

            
  • Runs in Session cwd
  • Default path is uncontained
  • Host PATH/HOME/SSH_AUTH_SOCK retained

          

          

            03 / volli help
            
CLI docs are on demand

            
The Brief contributes one two-sentence pointer. Only if the model runs volli help does its stdout enter context as a bash tool result.

            
  • No full reference preload
  • CLI and tool doors differ
  • SESSION TOOLS names the frozen tool-only verbs

          

          

            04 / skills
            
Metadata first, body later

            
Auto skills contribute name, path, and description to a 2,048-character bounded index. A /slug appends the full body after user text; model activation uses an ordinary read.

            
  • Project beats personal by slug
  • Auto / Manual / Off policy
  • Overflow is disclosed without disabling permitted /skill invocation

          

          

            05 / ports
            
Live boundaries answer

            
Web, browser, questions, background shells, and Volli verbs are offered only when a live port can answer. Results are bounded and wrapped before Pi appends them.

            
  • Untrusted page text gets minted markers
  • Background shell reads return deltas
  • Absence means uncallable

          

          

            06 / images
            
Attachments take two routes

            
Materialized files are named by relative path in the Brief. Supported images also ride the Pi user message as image blocks when the selected model can see them.

            
  • Stored outside prompt text
  • Persisted in Pi recovery sidecar
  • Budgeted upstream

          

        


        

          Current execution posture
          

            The default piExecutionEnv is uncontained: cwd points Pi's
            file and bash tools at the Session workspace, but is not a filesystem sandbox. The
            child environment is narrowed, while PATH, HOME, and SSH_AUTH_SOCK remain for working
            toolchains. A project's enforce mode can install Volli's before-tool-call
            gate; the default observe posture does not hand that gate to Pi.

06 · Ownership

            
What Pi actually owns.

          

          

            Volli uses Pi's lower-level Agent, not Pi's coding-agent product shell.
            “Pi-backed” does not mean Pi discovers Volli's instructions or owns Session truth.
