This page records capability changes for agents and automation. It is not a
commit log, and not the app's user-facing release changelog.

Run `volli help changes` to see the source revision and build ID of the CLI
bundle answering now, plus the running app version when the optional local read
succeeds. The release version is a separate promotion marker.
