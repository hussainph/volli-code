Shortcuts are grouped by the surface they act on. Terminals claim shell
keystrokes first, but Session and terminal-layout shortcuts still work there.

## Global

| Shortcut | Action |
| --- | --- |
| `⌘K` | Open the command palette |
| `C` | New ticket |
| `⌘1` to `⌘9` | Switch to the first through ninth project in the rail |
| `⌘B` | Toggle the sidebar |
| `⌥⌘B` | Toggle the visible ticket or Home rail |
| `⌘T` | Start a chat Session on the visible ticket or project |
| `⌥⌘T` | Start a terminal companion on the visible ticket or project |
| `⌥⌘Enter` | Enter or leave terminal focus mode for the visible terminal |
| `⌘[` | Back |
| `⌘]` | Forward |
| `⌘+` / `⌘-` / `⌘0` | Zoom the app in, out, or back to actual size |

The command palette searches tickets and sessions across every project.
Selecting a session opens it; selecting a ticket opens its workspace, switching
projects on the way if it belongs to another one.

`C` is a bare keypress with no modifier, so Volli suppresses it while you're
typing: in text fields, in the editor, in a terminal, or with a dialog already
open. `⌘[` behaves the same way, since it means outdent inside an editor.

<Aside type="note">
  `⌘K` does nothing while a terminal has focus. Terminals get first claim on
  keystrokes so that shell and agent bindings keep working.
</Aside>

## Board

| Shortcut | Action | When |
| --- | --- | --- |
| `Esc` | Deselect the selected card | A card is selected |
| `Enter` | Open a focused card | A card has keyboard focus |
| `Enter` | Add the card and keep the composer open | The inline composer is open |
| `Esc` | Close the inline composer | The inline composer is open |

## New ticket dialog

| Shortcut | Action |
| --- | --- |
| `⌘Enter` | Create the ticket |
| `⇧⌘Enter` | Create the ticket and start its agent |

## Ticket detail

| Shortcut | Action | When |
| --- | --- | --- |
| `Esc` | Close the ticket and return to the board | Nothing else has focus |
| `⌘Enter` | Post a comment | The comment box has focus |
| `Esc` | Cancel an in-progress comment edit | You're editing a comment |

`Esc` won't close the ticket while a terminal has focus. It goes to the
terminal instead, where it usually means "interrupt".

## Session composer

| Shortcut | Action |
| --- | --- |
| `Enter` or `⌘Enter` | Send the message |
| `⇧Enter` | Insert a new line |
| `Enter` | Choose the active `@` or `/` picker item when a picker is open |
| `Esc` | Close the active picker |

## File editor

| Shortcut | Action |
| --- | --- |
| `⌘S` | Save the open file |

## Terminal

| Shortcut | Action |
| --- | --- |
| `⌘D` | Split the pane vertically |
| `⇧⌘D` | Split the pane horizontally |
| `⌘⌥←` `⌘⌥→` `⌘⌥↑` `⌘⌥↓` | Move focus to the adjacent pane |
| `⌥⌘Enter` | Enter or leave terminal focus mode |
| `⌘+` / `⌘-` | Change the terminal font size |
| `⌘0` | Reset the terminal font size |

Font-size shortcuts change the focused terminal only. To scale the whole app,
move focus out of the terminal first.

## Canvas editor

| Shortcut | Action | When |
| --- | --- | --- |
| `←` `→` `↑` `↓` | Move the color 1% across the pad | A color on the pad has focus |
| `⇧` + an arrow | Move the color 5% across the pad | A color on the pad has focus |
| `←` `→` `↑` `↓` | Change grain by 1%, or 5% with `⇧` | The grain dial has focus |
| `Enter` | Apply the typed hex | The primary color's hex field has focus |
| `Esc` | Discard the typed hex | The primary color's hex field has focus |

Every other edit saves as you make it. See [Theming](/guides/theming/).
