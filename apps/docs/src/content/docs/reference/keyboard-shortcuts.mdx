Shortcuts are grouped by the surface they act on. Global shortcuts work anywhere
unless a terminal has focus.

## Global

| Shortcut | Action |
| --- | --- |
| `⌘K` | Open the command palette |
| `C` | New ticket |
| `⌘1` to `⌘9` | Switch to the first through ninth project in the rail |
| `⌘B` | Toggle the sidebar |
| `⌥⌘B` | Toggle the ticket detail rail |
| `⌘[` | Back |
| `⌘]` | Forward |
| `⌘+` / `⌘-` / `⌘0` | Zoom the app in, out, or back to actual size |

The command palette searches tickets and sessions across every project, and
carries **Change theme…** as an action. Selecting a session opens it; selecting
a ticket opens its workspace, switching projects on the way if it belongs to
another one.

`C` is a bare keypress with no modifier, so Volli suppresses it while you're
typing: in text fields, in the editor, in a terminal, or with a dialog already
open. `⌘[` behaves the same way, since it means outdent inside an editor.

<Aside type="note">
  `⌘K` does nothing while a terminal has focus. Terminals get first claim on
  keystrokes so that shell and agent bindings keep working.
</Aside>

## Board

| Shortcut | Action | When |
| --- | --- | --- |
| `Esc` | Deselect the selected card | A card is selected |
| `Enter` | Add the card and keep the composer open | The inline composer is open |
| `Esc` | Close the inline composer | The inline composer is open |

## New ticket dialog

| Shortcut | Action |
| --- | --- |
| `⌘Enter` | Create the ticket |
| `⇧⌘Enter` | Create the ticket and start its agent |

## Ticket detail

| Shortcut | Action | When |
| --- | --- | --- |
| `Esc` | Close the ticket and return to the board | Nothing else has focus |
| `⌘Enter` | Post a comment | The comment box has focus |
| `Esc` | Cancel an in-progress comment edit | You're editing a comment |

`Esc` won't close the ticket while a terminal has focus. It goes to the
terminal instead, where it usually means "interrupt".

## Terminal

| Shortcut | Action |
| --- | --- |
| `⌘D` | Split the pane vertically |
| `⇧⌘D` | Split the pane horizontally |
| `⌘⌥←` `⌘⌥→` `⌘⌥↑` `⌘⌥↓` | Move focus to the adjacent pane |
| `⌘+` / `⌘-` | Change the terminal font size |
| `⌘0` | Reset the terminal font size |

Font-size shortcuts change the focused terminal only. To scale the whole app,
move focus out of the terminal first.

## Theme picker

| Shortcut | Action |
| --- | --- |
| `Enter` | Apply the highlighted theme |
| `Esc` | Cancel and revert the preview |

Moving through the list previews each theme live. Nothing is saved until you
press `Enter`. See [Theming](/guides/theming/).
