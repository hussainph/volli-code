Volli Code is a local-first macOS app. It stores projects, tickets, Session
history, and worktrees on your machine. Volli itself requires no account;
model requests go to the provider you select through Model Access.

## In development

**Automations** are being built as saved board triggers. They will open Sessions
with defined instructions and recorded outcomes. They are not a setup option in
the current app.
