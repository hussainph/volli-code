Volli keeps a task's brief, its chats, its Git branch, and its changes in one
workspace. It runs on your Mac, and its built-in chats use a model provider you
connect.

<Aside type="caution" title="Alpha">
  Volli runs on Apple silicon Macs. Keep your own backups and Git branches.
</Aside>

## Work on a task

- [Manage tickets](/guides/manage-tickets/): write a brief, set properties, and track work.
- [Use a chat](/guides/sessions/): start, interrupt, and return to an agent conversation.
- [Review and publish changes](/guides/review-changes/): inspect diffs, test, commit, and open a pull request.
- [Clean up worktrees](/guides/clean-up-worktrees/): remove checkout folders without losing the branch.

## Configure your workflow

- [Models and usage](/guides/models/): connect providers and choose defaults.
- [Browser Tabs](/guides/browser-tabs/): watch an agent use a page and take control.
- [Skills and commands](/guides/skills-and-commands/): reuse instructions and templates.
- [MCP servers](/guides/mcp-servers/): connect external tools to a project.
- [Automations](/guides/automations/): save instructions and choose when they run.
