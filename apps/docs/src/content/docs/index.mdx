Volli Code is a local-first macOS workspace for parallel coding agents. Turn a
rough idea into focused tasks yourself, or ask an agent to help break it down.
Run independent tasks in parallel, then inspect their changes before you merge.

In Volli, a task is a **ticket**. Each ticket keeps its brief, chat history,
Git branch, and changes together. Projects, tickets, chat history, and
worktrees stay on your machine. Volli itself needs no account. You sign in to a
model provider through Model Access, and model requests go there.

<Aside type="caution" title="Alpha">
  Volli Code is in early alpha, for Apple silicon Macs. Features move between
  builds. See [Install](/start/install/) for what that means in practice, and
  [open an issue](https://github.com/hussainph/volli-code/issues) when something
  is wrong.
</Aside>

## Getting help

Bugs and confusion belong in [GitHub issues](https://github.com/hussainph/volli-code/issues).
Anything security-sensitive should go through
[private vulnerability reporting](https://github.com/hussainph/volli-code/security/advisories/new)
instead. If something is misbehaving on your machine, start with
[Troubleshooting](/reference/troubleshooting/).
