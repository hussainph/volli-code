Volli Code currently ships as a source build for macOS. There is no packaged
download yet.

## Requirements

You need a Mac, [git](https://git-scm.com), Node `^24.13.0`, and pnpm
`11.10.0`. The repository pins the Node and pnpm versions it uses.

<Steps>

1. Clone the repository and install dependencies.

   ```sh
   git clone https://github.com/hussainph/volli-code.git
   cd volli-code
   pnpm install
   ```

2. Start the development app.

   ```sh
   pnpm dev
   ```

   This runs the renderer with hot reload and relaunches Electron after main
   process changes.

3. To run a built copy instead, build first.

   ```sh
   pnpm run build
   pnpm start
   ```

</Steps>

<Aside type="tip">
  If a native dependency fails to build, run
  `pnpm -C apps/desktop run rebuild:native`. This rebuilds the native modules
  for Electron.
</Aside>

## Choose Model Access

Before you start a structured Session, open **Settings** and choose a default
model in **Model Access**. Model Access shows the accounts and models available
to Volli without exposing credentials in the app's Session history.

If a provider needs sign-in or a refresh, use the recovery action shown there.
Volli does not silently switch to a different model or account.

## The `volli` CLI

Volli includes a local `volli` command for working with the running app. The
app can install it for terminals outside Volli; the terminal companions it
opens already receive it on `PATH`.

Run this from a supported terminal companion to confirm its context:

```sh
volli identify
```

See the [CLI reference](/reference/cli/) for commands and connection details.

## Local data

Volli keeps its data on your Mac:

- Projects, tickets, labels, and history live in a SQLite database in
  Electron's `userData` directory.
- Ticket worktrees live under `~/.volli/worktrees/`.
- Session transcripts are stored on disk and indexed locally.

Model requests leave the app for the provider you select through Model Access.
Volli does not expose provider credentials in the renderer or Session history.

Removing a project from Volli does not remove its folder from disk.
