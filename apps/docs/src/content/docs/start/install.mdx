Install Volli on an Apple silicon Mac. Volli itself needs no account; its
built-in chats use a model provider you connect.

<Aside type="caution" title="Alpha">
  Features and behavior can change between builds. Keep your own backups and
  Git branches for work you cannot afford to lose.
</Aside>

## Requirements

| Requirement | Supported setup |
| --- | --- |
| Mac | Apple silicon, M1 or later; no Intel build |
| macOS | 12.0 Monterey or later |
| Git | Installed, with a repository on disk |
| Model provider | An account or API key for a provider available in Volli |

## Install the app

1. Download the `.dmg` from [volli.app/download](https://volli.app/download/).
2. Open the disk image and drag **Volli Code** to **Applications**.
3. Open **Volli Code** from **Applications**.
4. In **Settings → Models**, connect a provider and choose a default model.
   See [Models and usage](/guides/models/) for the available account controls.

Continue with [Run your first coding task](/start/quickstart/) to add a
repository, create a ticket, and review an agent's change.

If the app cannot open, record the exact macOS message and see
[Troubleshooting](/reference/troubleshooting/). Do not disable macOS security
checks to work around an unexplained failure.

## Updates

**Settings → Updates** shows the installed version and update checks. Available
updates download in the background and install when you quit.

You can also download a release's `.dmg` from
[GitHub Releases](https://github.com/hussainph/volli-code/releases) and replace
the app in **Applications**.

## The volli CLI

Terminal companions opened by Volli have `volli` on `PATH`. Check their context
with `volli identify`. **Settings → About** checks and repairs the parts of the
installation Volli owns. See [CLI setup and context](/reference/cli/).

## Where your data lives

Volli stores app data under `~/Library/Application Support/Volli Code/` and
ticket worktrees under `~/.volli/worktrees/`. Removing a project from the app
does not delete its repository folder.

See [Local data and network access](/reference/data-and-privacy/) for storage
and outbound requests, and [Storage and backups](/guides/storage/) before
removing app data.

## Uninstall

1. Quit Volli.
2. Remove worktrees you no longer need through Git. Follow
   [Clean up worktrees](/guides/clean-up-worktrees/) before deleting folders.
3. Drag **Volli Code** from **Applications** to the Trash.

App data remains on disk. Deleting
`~/Library/Application Support/Volli Code/` removes local tickets, histories,
and settings. Back it up first if you need to retain them. Uninstalling does
not remove your project repositories.
