Install Volli on an Apple silicon Mac. Volli needs no account of its own, but
its built-in chats use a model provider you connect.

<Aside type="caution" title="Alpha">
  Features and behavior change between builds. Keep backups and Git branches
  for work you cannot lose.
</Aside>

## Requirements

| Requirement | Supported setup |
| --- | --- |
| Mac | Apple silicon, M1 or later; no Intel build |
| macOS | 13.0 Ventura or later |
| Git | Installed, with a repository on disk |
| Model provider | An account or API key for a provider available in Volli |

## Install the app

1. Download the `.dmg` from [volli.app/download](https://volli.app/download/).
2. Open the disk image and drag the Volli app to **Applications**.
3. Open Volli from **Applications**.
4. In **Settings → Models**, connect a provider and choose a default model.
   See [Models and usage](/guides/models/) for more on providers and models.

Continue with [Run your first coding task](/start/quickstart/) to add a
repository, create a ticket, and review an agent's change.

If the app will not open, note the exact message macOS shows and see
[Troubleshooting](/reference/troubleshooting/). Do not disable macOS security
checks to get past a failure you cannot explain.

## Updates

**Settings → Updates** shows your current version and has a **Check now**
button. An available update downloads in the background and installs the next
time you quit.

You can also download a release's `.dmg` from
[GitHub Releases](https://github.com/hussainph/volli-code/releases) and replace
the app in **Applications**.

## The volli CLI

Terminal companions you open from Volli have `volli` on `PATH`. In one of
them, run `volli identify` to check its context. **Settings → About** checks and
repairs the parts of the installation that Volli owns. See
[CLI setup and context](/reference/cli/).

## Where your data lives

Volli stores app data under `~/Library/Application Support/Volli Code/` and
ticket worktrees under `~/.volli/worktrees/`. Removing a project from the app
does not delete its repository folder.

See [Local data and network access](/reference/data-and-privacy/) for what
Volli stores and what it sends out, and [Storage and backups](/guides/storage/)
before you delete app data.

## Uninstall

1. Quit Volli.
2. Remove the worktrees you no longer need with Git. Follow
   [Clean up worktrees](/guides/clean-up-worktrees/) before you delete a folder.
3. Drag the Volli app from **Applications** to the Trash.

App data stays on disk. Deleting
`~/Library/Application Support/Volli Code/` removes your local tickets,
histories, and settings, so back it up first if you need them. Your project
repositories stay where they are.
