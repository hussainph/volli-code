A ticket is a task in Volli. Open one to read its **Ticket Body**, return to
its chats, inspect files and diffs, and edit its properties. The main tab strip
keeps the documents and chats you open. The rail beside it has four pages:
**Now**, **Diffs**, **Files**, and **Search**.

## Now

**Now** shows what is true of the whole ticket, in three sections:

- **Properties**: status, priority, and labels. Changing status updates the
  board. Starting a chat or an Automation Run is a separate action.
- **Sessions**: the ticket's chats and terminal sessions. Ended Sessions are
  folded under the section heading. Open one to return to its history.
- **Automations**: the saved Automations this ticket can run.

The ticket's cost is a row pinned at the bottom of **Now**. The worktree row is
pinned under every page: it shows the branch and opens to the base branch,
worktree, changes, and pull-request state.

A ticket chat carries the task's context and works from that ticket's worktree.
Reconnecting it does not create a second chat history. What one chat is holding,
such as its Browser Tabs, subagents, plan, and background shells, is shown in
the Activity Island above that chat's composer, not in the rail.

Use **Chat** in the **Sessions** heading to open a draft after configuring
[Models](/guides/models/). Send the first message to start the Session. The
**Chat** menu also opens a [terminal companion](/guides/terminal-companions/)
or a [Browser Tab](/guides/browser-tabs/).

### Run an Automation on this ticket

The **Automations** section lists the Automations offered to this ticket. The
one armed for the ticket's current column comes first and is marked. Select a
row, or right-click it, to see its saved Instructions, choose the model for
this Run under **Run on**, and select **Run**. Selecting a row never starts a
Run by itself. A manual Run is available even when **Automatic triggers** is
off for that Automation.

The Run opens a fresh Session, which appears in **Sessions** with a mark
showing that a Run started it. The Automations section does not list Runs.
Select **Open Automations** in the section heading to create or edit records;
authoring lives only on that page. For one-off work that you don't want to
save, start a chat instead.

## Files and references

The **Files** rail shows file references from the Ticket Body, attached files,
and the ticket worktree's directory tree. Use `@` in the Ticket Body to add a
file reference. Selecting a file opens a preview tab; keeping it open pins the
tab.

Ticket files read from the worktree. The project-level **Files** navigator in
**Home** reads from the main checkout, so the same path can contain different
content in each place. Editing one does not edit the other.

## Diffs

The **Diffs** rail compares the ticket worktree with its base branch. Open a
file to inspect its diff. The change set includes committed and uncommitted
work, so it reflects the branch as it is on disk. See
[Review and publish changes](/guides/review-changes/) for testing, commits,
and pull requests.

## Search

The **Search** rail searches files in the ticket's worktree. For tickets and
Sessions across projects, use the command palette, `⌘K`.

<Aside type="note">
  Worktrees are retained when a ticket is archived. See
  [Chats and worktrees](/guides/agents-and-worktrees/#change-sets-and-retained-worktrees)
  for safe removal after the branch is landed.
</Aside>
