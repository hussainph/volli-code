A **Browser Tab** shows a web page inside Home or a Ticket view. You can
open one yourself, or show a page a Session opened while it worked.

## Open a Browser Tab

1. In Home or a Ticket view, open the menu beside **Chat**.
2. Select **Browser**.
3. In the Browser Tab's **Address** field, enter an HTTP or HTTPS URL and press Return.

A project can have up to 32 person-created tabs. Each Session can own up to
six headless agent tabs; there is no project-wide cap on agent tabs. Close or
reuse a tab when you reach the limit. Local file URLs are not supported.

Browser Tabs run inside Volli, sandboxed from the rest of the app. Treat
everything on a page as untrusted: a Session never treats what it reads on a
page as an instruction, and neither should you, even though the page appears
inside Volli. Pages send requests to their own websites, and what you click or
type can be sent there too. See
[Local data and network access](/reference/data-and-privacy/).

## Show a page a Session opened

A Browser Tab a Session opened starts hidden. Its card appears in that
Session's chat, and its page is listed in the Activity Island. Choose
**Open beside chat** to show it next to its owning chat as one joined tab pair.
Other tabs fill the workspace; selecting either pair member restores both panes.
Legacy preview tabs remain in the Island and open beside their chat the same way.

Showing a Session tab only changes where it appears; the Session keeps using
it. You can also close a page a Session opened from its card. A tab you show
becomes yours and remains available after its Session ends. When a delegated
subagent finishes its task, Volli closes its unheld, hidden tabs. Tabs you are
holding or another Session holds stay open.

## Take or return control

When a Session is driving a Browser Tab, its name appears beside the address
field with a **Take over** and **Ask to leave** control.

- Choose **Take over** to take the tab's turn now. Volli tells the Session that
  it no longer holds the tab.
- Choose **Ask to leave** to ask the Session to release the tab when it is
  safe. The Session keeps control until it releases the tab.
- When the tab is yours, choose **Hand back** to release it. The tab becomes
  available, and a Session can take it on a later write.

You can always click or type into the page, even while a Session holds it.
Using the address field or the Back, Forward, and Reload controls does not
itself change who holds the tab.

<Aside type="note">
  A Session can see the tabs it opened and the tabs you opened, but not tabs
  opened by other Sessions. **Take over**, **Ask to leave**, and **Hand back**
  change whose turn it is to drive a tab, not who owns it.
</Aside>
