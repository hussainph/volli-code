A **terminal companion** is a shell you open in Volli. Run your own commands
there, or an external terminal UI (a TUI) such as Claude Code or Codex. It is a
manual workflow alongside chat; Volli never opens one as a fallback when a chat
fails.

## Open a terminal

1. In Home or a ticket workspace, open the menu beside **Chat**.
2. Select **Terminal**. You can also use `⌥⌘T`.

A Home terminal starts in the project's main checkout. A ticket terminal uses
the ticket's selected destination: its worktree, or the project's **Project
checkout**. If the ticket needs a worktree, Volli creates it when the terminal
starts. When Volli has just created that worktree, a configured **Then run**
setup command runs first.

The terminal opens as a Session with a shell. To use an external TUI, start it
from that shell yourself. Volli never starts one for you. Choose **Chat** when
you want Volli's built-in agent conversation and tools.

## Use the `volli` CLI

A supported terminal companion can call Volli's `volli` CLI through the local
Unix socket. Use it to inspect tickets and worktree state, or to report progress
to the app. See the [CLI reference](/reference/cli/) for commands, arguments,
and the difference between read and write operations.

## Understand terminal history

A terminal keeps a Session record, but Volli does not save its shell output or
commands. If Volli quits, the live terminal process and its scrollback do not
resume when you reopen the app. The saved record shows the terminal's scope,
when it started and ended, and its exit code. It does not reproduce the
terminal screen.

A new terminal is a new Session. If a closed terminal record offers **Resume
session**, that resumes a supported TUI's own history in a new terminal; it is
not a copy of the old shell or its scrollback.

<Aside type="note">
  A ticket worktree is separate from the project's main checkout. Changes you
  make in one do not automatically appear in the other. See [Chats and
  worktrees](/guides/agents-and-worktrees/) for branch and file-copy behavior.
</Aside>
