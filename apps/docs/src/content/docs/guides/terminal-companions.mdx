A **terminal companion** is a shell you open in Volli for commands or an
external terminal UI (TUI). You choose what to run there. It is a manual
workflow alongside built-in chat, not a fallback when a chat cannot start.

## Open a terminal

1. In Home or a ticket workspace, open the menu beside **Chat**.
2. Select **Terminal**. You can also use `⌥⌘T`.

A Home terminal starts in the project's main checkout. A ticket terminal uses
the ticket's selected destination: its worktree, or the project's **Project
checkout**. If the ticket needs a worktree, Volli creates it when the terminal
starts. A configured **Then run** setup command runs first, when Volli has just
created that worktree.

The terminal opens as a Session with a shell. To use an external TUI, start it
from that shell yourself. Volli does not silently launch an external harness
when built-in chat fails. Choose **Chat** when you want Volli's built-in agent
conversation and tools.

## Use the `volli` CLI

Supported terminal companions can call Volli's `volli` CLI through the local
Unix socket. Use it to inspect tickets and worktree state or report progress to
the app. See the [CLI reference](/reference/cli/) for commands, arguments, and
the difference between read and write operations.

## Understand terminal history

A terminal has a durable Session record, but its shell output and commands are
not saved. If Volli quits, the live terminal process and its scrollback do not
resume when you reopen the app. The saved record can show its scope, start and
end, and observed exit code; it does not reproduce the terminal screen.

A new terminal is a new Session. If a closed terminal record offers **Resume
session**, that resumes a supported TUI's own history in a new terminal; it is
not a copy of the old shell or its scrollback.

<Aside type="note">
  A ticket worktree is separate from the project's main checkout. Changes you
  make in one do not automatically appear in the other. See [Chats and
  worktrees](/guides/agents-and-worktrees/) for branch and file-copy behavior.
</Aside>
