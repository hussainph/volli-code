**Settings** applies across the app. **Configure** belongs to the selected
project. Saved Automation records and their **Automatic triggers** switches live
on the [Automations](/guides/automations/) page.

## Settings

Open **Settings** from the sidebar's gear control.

| Page | Controls |
| --- | --- |
| **General** | Project switcher and sidebar visibility |
| **Appearance** | App, editor, and terminal appearance; display zoom and diff layout |
| **Notifications** | Native notifications for input, pull requests, cleanup, and updates |
| **Models** | Provider access, model visibility, defaults, reasoning, and automatic compaction |
| **Web Search** | Search provider and its connection settings |
| **Integrations** | External editor and terminal choices, including **Ask every time** |
| **Storage** | Retention, leftover processes, build artifacts, logs, worktrees, and data export |
| **Telemetry** | Optional agent telemetry to a collector you specify |
| **Updates** | Installed version, update channel, and update checks |
| **About** | Installation, CLI, and terminal-companion health checks; support report |

Follow [Models and usage](/guides/models/), [Theming](/guides/theming/), or
[Manage local storage](/guides/storage/) for those tasks. Subscription usage
windows appear in the usage-limits popover beside the `⌘K` search, not on the
**Models** page.

## Configure

Select your project, then open **Configure**.

| Page | Controls |
| --- | --- |
| **Skills** | Available Skills and their prompt budget |
| **Commands** | Project slash-command templates |
| **MCP Servers** | Server connections and tools offered to new Sessions |
| **Authority** | Project policy, enforcement posture and containment |
| **Sessions** | Project Session defaults and instruction precedence |
| **Appearance** | Project overrides for the app, editor, and terminal |
| **Worktrees** | Base branch and setup command for new ticket worktrees |

See [Skills and commands](/guides/skills-and-commands/), [MCP
servers](/guides/mcp-servers/), and [Agent authority](/guides/authority/) for
agent configuration. [Chats and worktrees](/guides/agents-and-worktrees/)
explains base branches, setup, and `.worktreeinclude`.

A project appearance override can inherit or replace an app-wide value. A
Session's tools and authority have their own recorded lifetimes, so changing a
setting does not necessarily change an existing Session. Check the relevant
guide before relying on a policy change.

## Web Search

In **Settings → Web Search → Provider**, choose **Off**, **Brave**, **Exa**, or
**SearXNG**. Brave and Exa need an API key. SearXNG needs an instance URL.
Saved keys are not displayed again.

Turning search off does not turn off model requests, Browser Tabs, or web
reads. See [Local data and network access](/reference/data-and-privacy/).
