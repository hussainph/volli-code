Open a ticket to update its scope and properties, discuss the work, or review
what changed. The **Ticket Body** holds the ticket's Markdown scope. The **Now**
rail shows its **Properties** and Session history.

## Update ticket details

Select the ticket title to edit it. Edit the **Ticket Body** in its tab; changes
autosave. In **Now → Properties**, change the ticket's **Status**, **Priority**,
or **Labels**. A status change also moves the ticket on the board.

Labels belong to the project. Use **Add label** to pick an existing label, or
type a new name and choose the create option to add it to the project.

## Comments

The **Activity** feed appears below the Ticket Body. Add a comment in its
composer, then select **Comment** or press `⌘Enter`. Comments render as
Markdown.

Use **Edit comment** or **Delete comment** on your own comments. An edited
comment shows an “edited” mark beside its time. You cannot edit or delete a
comment a Session wrote.

## History

The **Activity** feed shows comments and ticket events, such as changes to
status, priority, labels, and the Ticket Body. Expand a grouped row to inspect
each event.

## Archiving

Right-click the ticket's card and select **Archive** to take it off the board
without deleting it. The ticket, its history, branch, and worktree stay
available. The archive control in the board header opens the project's archived
tickets.

Select **Restore** to return a ticket to the board. **Delete permanently**
removes an archived ticket and its full history, and cannot be undone. Archiving
a ticket does not remove its worktree. See [Clean up worktrees](/guides/clean-up-worktrees/)
for removal and retention behavior.
