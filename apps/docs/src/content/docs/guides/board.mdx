The board organizes tickets across five fixed columns. Drag a ticket to change
its status, or open its workspace to edit ticket details and review its
activity. A move alone does not start a Session; an enabled, armed Automation
can start a fresh Ticket Session when a deliberate move brings a ticket into
its column.

![The Home Board for voltaic with all five columns and 24 tickets visible; the navigation sidebar is hidden so the columns fit, and VLT-14 appears in Doing with composer and renderer labels.](../../../assets/screenshots/board.png)

## The columns

- **Backlog** holds work you have recorded but are not ready to schedule.
- **Todo** holds work you plan to do next.
- **Doing** marks active work.
- **Needs Review** marks work ready for inspection.
- **Done** marks finished work. A ticket remains on the board until you archive
  it.

## List view

Use the view control beside the ticket count to switch between **Board** and
**List**. Board shows cards in columns; List shows the same tickets as rows,
grouped by column. Switching views keeps the current filters and sort order.

## Filtering and sorting

Use the board header's **Priority** filter, or **Label** when the project has
labels, to narrow the visible tickets. Each filter accepts multiple values and
matches any selected value. Select **Clear** to reset active filters.

Choose **Manual**, **Priority**, **Created**, **Updated**, or **Title** to sort
tickets within each column. **Manual** keeps the order you set by dragging;
other sort fields let you choose ascending or descending order. Sorting by a
field does not change the saved manual order.

Use the command palette (`⌘K`) to search tickets and Sessions across projects.

## What moves a ticket

Drag a card to another column, or choose **Move to** from its context menu.
In a ticket workspace, changing **Status** under **Properties** also moves it.
The `volli ticket move` command makes the same explicit move from a terminal.

A Deliberate move records the destination you chose, whether you made it or a
Ticket Session used `volli ticket move`. A Session's completion or blocked
signal records its outcome; it does not change the ticket's status. Moving from
**Doing** or **Needs Review** to **Backlog**, **Todo**, or **Done** interrupts the
ticket's live Sessions. Moving between **Doing** and **Needs Review** does not.

### Manual moves win

Volli keeps the status chosen by a deliberate move; a Session ending does not
move the ticket to another column.

## Automations on the board

The lightning control in a column header chooses which offered Automation can
start when a ticket enters that column. A column can offer several Automations
but can arm only one. A manual Run remains available when automatic triggers
are off. See [Arm a column Automation](/guides/automations/columns/) for
machine-local enablement, column arming, and Option-drag choices.

## The ticket context menu

Right-click a ticket to open its context menu. Use **Move to**, **Priority**, or
**Labels** to update it; run an offered Automation from **Automations**; or use
**Resume last session** when Volli offers it. **Archive** keeps the ticket for
later restoration. **Remove worktree…** removes its checkout but keeps the
branch. See [Manage tickets](/guides/manage-tickets/) for ticket activity and
archiving, and [Clean up worktrees](/guides/clean-up-worktrees/) before you
remove a checkout.
