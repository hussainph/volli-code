Use a schedule to start the same Automation at a recurring time. A scheduled Run
targets its project and opens a project-level Board Session.

## Set the schedule

1. Open **Automations** in the app navigation, then select **New Automation**.
2. In **Name**, enter a name you can recognize in a run menu.
3. In **Instructions**, write the first message the new Session should receive.
4. Under **Trigger**, select **On a schedule**. Scheduled Automations belong to
   **This project**.
5. Select a cadence under **Schedule**:
   - **Hourly** runs at a chosen number of minutes past the hour.
   - **Every day** runs at a chosen time each day.
   - **Mon–Fri** runs at a chosen time on weekdays.
   - **Weekly** runs on a chosen day and time.
6. Choose a **Time zone**. A new schedule starts with this Mac's current time
   zone. The saved zone stays in effect if you travel.
7. Select **Create automation**.
8. Turn on **Automatic triggers** in the Automation's header on this Mac.

While **Automatic triggers** is on, the schedule shows **Next:** with the next
due time in this Mac's local time and time zone. It follows the time you are
editing, so select **Save changes** for a new time to take effect. Turning
**Automatic triggers** off removes the line.

Schedules use these presets; they do not accept cron expressions. For a due Run
to start on time, the app must be running and the Mac awake. A Run may start up
to 2 minutes after its due time; later than that, the occurrence is skipped.

## Handle a missed occurrence

If a due time passes while Volli is closed, or the Mac is asleep or too busy to
wake in time, history records a **Skipped** occurrence with its reason.
Volli does not replay missed work; the next occurrence follows the saved
cadence. To start the work anyway, select **Run now** on the skipped row. That
starts one project Run, even if the row covers several missed times.

Read the Run and its Session in [Run history](/guides/automations/run/). For
column-based automatic starts, see [Arm a column Automation](/guides/automations/columns/).
