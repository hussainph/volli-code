A **Columns** Trigger offers an Automation in the board columns you select.
To run it automatically, enable **Automatic triggers** and arm it in a column.
Arming does not start work on tickets already in that column.

<span id="configure-a-ticket-enters-trigger"></span>

## Configure a column Trigger

1. In your project's navigation, open **Automations** and select an Automation.
2. Beside **Trigger**, select **Edit**.
3. Select **Columns**, then check one or more board columns.
4. Select **Save**.

For a new Automation, configure the Trigger before selecting **Create**.
Each selected column offers the Automation in its list. A column can offer
several Automations but can arm only one.

## Enable and arm automatic starts

### Enable an Automation

In the Automation's **Trigger** section, turn on **Automatic triggers**. It is
off by default and applies only to this Mac. While it is off, you can run the
Automation by hand, but a column arrival or schedule will not start it.

### Arm a column

On the board, select the bolt in the column header, then choose the Automation.
Select **No automation** to disarm the column. If an armed Automation's
automatic starts are off, you can enable **Automatic triggers** in this menu.

You can also arm it in the editor: in **Trigger**, turn on **Arrival** for the
column. Arming a different Automation replaces that column's earlier choice.

An armed, enabled Automation starts only after a deliberate move into its
column, such as dragging a card, choosing **Move to**, or changing **Status**
in a ticket's **Properties**. Automatic lifecycle moves do not trigger it.
During the 3.5-second countdown, select **Cancel** to keep the move but skip
the Run.

In **Automations → Columns**, choose a column to see its offered list. Drag
rows to change their order. An armed Automation with **Automatic triggers** on
stays pinned first; you can reorder the others.

## Choose during a board drag

While dragging a ticket, hold **Option (⌥)** over a column to expand its offered
Automations into landing targets. Release on an Automation to run it for this
move, or release on **Move only** to change status without starting a Run.

Press **1** through **9** to choose an offered Automation, or **0** for
**Move only**. An armed Automation with **Automatic triggers** on takes the
first slot. A chosen Automation uses the same cancellable countdown as an armed
arrival. This is a
one-time choice: it does not change the column's arming or the Automation's
Trigger, and it can run even with **Automatic triggers** off.

For recurring times, see [Schedule an
Automation](/guides/automations/schedules/).
