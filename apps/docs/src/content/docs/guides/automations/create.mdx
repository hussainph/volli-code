Create a manual Automation when you want to reuse the same starting
instructions without setting up an automatic Trigger. You can run it by hand
whether or not **Automatic triggers** is on.

## Create an Automation

1. Open **Automations** in the app navigation, then select **New Automation**.
2. In **Name**, enter a name you can recognize in a run menu.
3. In **Instructions**, write the first message the new Session should receive.
4. Leave **Ownership** set to **This project** so the Automation belongs to
   this project.
5. Leave **Trigger** set to **Only when I run it**.
6. Leave **Runtime** set to **Project default** to use the project's Session
   default when a Run starts.
7. Select **Create automation**.

## Set a Runtime

**Project default** uses the model override in **Configure → Sessions → Chat**.
If the project inherits, Volli uses **Settings → Models → Ticket Sessions** for
a ticket Run or **Board chats** for a project Run, and chooses the model when the
Run starts. See [Model defaults](/guides/models/#choose-a-default-model).

To pin a different choice, select a named default tier or an exact model under
**Runtime**. If the model you select offers more than one reasoning level,
choose one under **Reasoning effort**. Each Run's history records the model and
reasoning that actually started its Session. Changing project defaults later
affects future Runs, not the history of Runs that already started.

In **Instructions**, enter `/` to choose a Command or Skill, or `@` to reference
a file. See [Skills and commands](/guides/skills-and-commands/). The Run sends
these Instructions as the first message in a fresh Session; it does not continue
an existing one.

The Automation appears in this project's Automations list. **Only when I run it**
means it has no automatic start, and you can still run it while **Automatic
triggers** is off. See [Run an Automation and read Runs](/guides/automations/run/)
to choose a ticket and open the Session it creates.

To start work from a board-column move or a schedule, use [column
Automations](/guides/automations/columns/) or [scheduled Automations](/guides/automations/schedules/).
