# The Volli 0.2 release film (VC-464)

A social cut (16:9 and 9:16) made with [Flute](https://github.com/webprodigies-org/flute)
by pointing a 3D camera at **real renderer components** running in the UI lab,
with fixture data. Lab-only: nothing in `src/renderer/src/` imports anything
here, and a production build contains no Flute code (the only import is behind
`import.meta.env.DEV` in `src/renderer/lab/main.tsx`).

## Layout

| Path | What |
| --- | --- |
| `ProjectPreview.jsx`, `catalog.js`, `../../.flute/`, `../../FLUTE.md` | Flute's portable React adapter, generated by `npx flute init --adapter react` / `npx flute sync`. Do not edit. |
| `scenes/<key>-wide.scene.json`, `scenes/<key>-tall.scene.json` | Flute recipes — **generated** by `scripts/film/recipes.mjs` from `scripts/film/shots/<key>.mjs`. Do not hand-edit. |
| `scenes/<key>-wide.tsx`, `scenes/<key>-tall.tsx` | One-line bindings: `<KeyShot format="landscape" />` / `"portrait"`. |
| `shots/<key>.tsx` | The shot: real components as `Surface`s, UI state driven from scene time, supers. |
| `kit/` | Shared film vocabulary: `clock.ts` (easing, tracks), `film.tsx` (`useFilm`, `useFixtures`, `FrameLayer`, `Supers`, `Vignette`), fixtures. |
| `../../scripts/film/` | `shots/<key>.mjs` camera rigs, `recipes.mjs` (writes recipes + `flute sync`), `capture.mjs` (renders stills / 4K masters), `cut.mjs` (stitches the cuts). |

Renders go to `apps/desktop/.film-out/` (gitignored). Video never lands in git.

## Rules

1. **Everything on screen is a real component.** Import from `@renderer/*`; never
   re-draw a component to make it easier to animate. Fixture data only.
2. **Scene time drives everything.** Call `useFilm()` once in the shot; derive every
   piece of UI state from its `t` (ms). No `setTimeout`, `setInterval`,
   `Date.now()` or wall-clock anything. Components' own CSS transitions and
   keyframes are fine — `useFilm` pins every document `Animation` to the scene
   clock — and `motion` springs run on the scene clock via manual timing.
3. **Speed is 1.** Authored ms = video ms.
4. **Public-safe.** No real emails (use `.example`), account ids, tokens, `/Users/…`
   paths or private usage numbers anywhere in frame.
5. **Only shipped 0.2 behaviour.** Not: Session hover-peek (VC-30), "Run once",
   MCP UI, native notifications, terminals, live browser pixels.
6. **Supers** are claims: each must be supported by the tickets it names in its
   eyebrow. Sizes come from `Supers` (≥ 84px at 1080 wide). In 9:16 all text
   stays between y=250 and y=1500.

## Loop

```sh
pnpm lab   # or: cd apps/desktop && npx vp dev --mode lab --port 5188
node scripts/film/recipes.mjs <key>                       # regenerate recipes
node scripts/film/capture.mjs <key>-wide --out .film-out/stills/<key>-wide --stills 0,800,1600
node scripts/film/capture.mjs <key>-wide --out .film-out/masters/<key>-wide.mp4   # 3840×2160, 60fps
node scripts/film/cut.mjs                                 # stitch both cuts
```

Scenes open at `/lab/?flute-preview=1&flute-scene=<key>-wide`.
